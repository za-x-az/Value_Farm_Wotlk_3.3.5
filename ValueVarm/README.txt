# ValueFarm		https://github.com/za-x-az/Value_Farm_Wotlk_3.3.5

A World of Warcraft addon for tracking farming value in real time.

## Features

- Tracks loot value and trash value while farming
- Start / Pause / Reset controls
- Mini mode for a compact HUD
- Configurable options window

## Installation

1. Download the latest release.
2. Extract the folder so the path looks like:
   ```
   World of Warcraft/_retail_/Interface/AddOns/ValueFarm/
   ```
3. Restart WoW or type `/reload` if it's already running.
4. Make sure ValueFarm is checked on the AddOns list at the character select screen.

## Usage

- `/valuefarm` or `/vf` — open the main window (adjust to your actual slash command)
- Click **Play/Pause** to start or stop tracking
- Click **Reset** to clear all tracked data
- Click **Options** to open settings
