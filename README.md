Farmin addon for WoW 3.3.5


This is still a Work In Progress.
Just sharing what i made for my self.

Please add any bugs or feature requests here on github.



/VF for commands

Usage: /vf [start|pause|reset|show|hide|mini|debug|debug clear|options|herb show|herb hide|prospect show|prospect hide|info]
start - Start tracking loot
pause - Pause tracking loot
reset - Reset all data
show - Show the ValueFarm window
hide - Hide the ValueFarm window
mini - Toggle mini mode
debug - Toggle debug window + logging
debug clear - Clear debug log
options - Open the options window
herb show - Show herb/ore counter window
herb hide - Hide herb/ore counter window
prospect show - Show prospecting tracker window
prospect hide - Hide prospecting tracker window
info - Show information about the addon
