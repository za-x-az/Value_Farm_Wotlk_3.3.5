Farmin addon for WoW 3.3.5


This is still a Work In Progress.
Just sharing what i made for my self.

Please add any bugs or feature requests here on github.



/VF for commands<br>
<br>
Usage: /vf [start|pause|reset|show|hide|mini|debug|debug clear|options|herb show|herb hide|prospect show|prospect hide|info]<br>
start - Start tracking loot<br>
pause - Pause tracking loot<br>
reset - Reset all data<br>
show - Show the ValueFarm window<br>
hide - Hide the ValueFarm window<br>
mini - Toggle mini mode<br>
debug - Toggle debug window + logging<br>
debug clear - Clear debug log<br>
options - Open the options window<br>
herb show - Show herb/ore counter window<br>
herb hide - Hide herb/ore counter window<br>
prospect show - Show prospecting tracker window<br>
prospect hide - Hide prospecting tracker window<br>
info - Show information about the addon<br>
